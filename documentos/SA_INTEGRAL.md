## Objetivo da UCR

Propiciar desenvolvimento de capacidades técnicas e socioemocionais requeridas para criação de aplicativos por meio de linguagem de programação, de acordo padrão de qualidade, robustez, integridade e segurança.

## Capacidades Técnicas

- CT1 Reconhecer ferramentas para o desenvolvimento de atividades (repositório, controle de versão).
- CT2 Instalar ferramentas de acordo com requisitos de hardware, software e parâmetro de configuração.
- CT3 Reconhecer especificações técnicas e paradigmas de linguagem de programação.
- CT4 Aplicar linguagem de programação por meio do ambiente integrado de desenvolvimento (ide).
- CT5 Integrar banco de dados por meio da linguagem de programação.
- CT6 Aplicar métodos e técnicas de programação.
- CT7 Empregar comentários para documentação do código fonte.
- CT8 Utilizar o ambiente de desenvolvimento (ide) para rastreabilidade do código.
- CT9 Identificar erros de acordo com o requisito do programa.
- CT10 Utilizar o ambiente de desenvolvimento (ide) para aplicação de teste  unitário.

- CS1 Apresentar comportamento ético no desenvolvimento das atividades sob a sua responsabilidade
- CS2 Aplicar os princípios de organização do trabalho estabelecidos no planejamento e no exercício de suas atividades profissionais
- CS3 Monitorar a execução de atividades assegurando o seu desenvolvimento

## CONTEXTUALIZAÇÃO

Uma empresa de tecnologia especializada no desenvolvimento de soluções sob medida para diferentes segmentos da indústria está em fase de expansão. O setor de engenharia de software foi encarregado de desenvolver novos sistemas para atender demandas de clientes que buscam automatizar processos e integrar dados operacionais.

Entre os projetos em andamento, há solicitações de desenvolvimento para sistemas como:

- Delivery de comida
- Aplicativo de transporte
- Loja de departamentos
- Streaming de vídeo
- Gerenciamento de estoque
- Hospital
- Escola
- Empresa de Recursos Humanos (RH)
- Oficina mecânica
- Fábrica de chocolate

Cada projeto possui particularidades, mas todos exigem a construção de um sistema funcional com modelagem de requisitos, estrutura de banco de dados e interface de aplicação.

## DESAFIO

O Técnico em Desenvolvimento de Sistemas foi contratado para desenvolver um dos projetos propostos à uma aplicação funcional que atenda às necessidades do cliente, assegurando qualidade, integridade, usabilidade e segurança das informações tratadas.

## RESULTADOS ESPERADOS

- Aplicação funcional documentada, composta por:
  - Banco de dados relacional implementado e normalizado;
  - Aplicativo programado e conectado ao banco de dados;
  - Documentação técnica contendo a modelagem do sistema.
- Apresentação à banca técnica.

## Contribuições da UC

- Código-fonte organizado e comentado;
- Interface funcional;
- Integração completa com o banco de dados (CRUD);
- Aplicativo programado e conectado ao banco de dados.
